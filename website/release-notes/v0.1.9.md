## Stow 0.1.9

This update fixes self-updates for apps installed with Quick Install and improves title readability while browsing archives.

- Keep apps installed with Quick Install running from their installation folder, so their own updaters can work. Download quarantine and Gatekeeper checks stay in place.
- Apply the installation fix to new installs, replacement and Keep Both. Explain how to finish in Finder if macOS cannot prepare the installed app.
- Keep scrolled files from showing sharply behind the Browser and new-archive window titles, with support for Reduce Transparency and Increase Contrast.
- Fix an exFAT extraction edge case involving empty metadata companion files.

Requires macOS 26 or later.
