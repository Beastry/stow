## Stow 0.1.10

This update fixes Quick Look previews that kept spinning for small Markdown and Office documents.

- Allow the system WebKit renderer to start correctly for full document previews. The archive engine and 7-Zip remain sandboxed without network access.
- Stop stalled thumbnail requests after ten seconds and cancel obsolete requests when their view disappears.
- Keep cached preview files available while Quick Look is using them.

Requires macOS 26 or later.
