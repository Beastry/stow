## Stow 0.1.5

This update adds independent archive windows, a workspace for creating archives, and more flexible Tray and packing workflows.

- Open multiple archives in separate windows and copy entries between archives by dragging them.
- Build a new archive in an editable workspace, arrange its contents, and choose packing options when saving. Failed saves keep the draft available to retry.
- Keep Stow available in the menu bar with optional Tray residency. Drop files on the Tray icon, or hold them over it to open the Tray; export a temporary result with Save To.
- Choose default archive formats and compression levels in Settings, and enter a specific CPU thread limit for packing.
- Reuse verified passwords across batch extraction, with an option to skip an archive and continue.
- Source-archive cleanup now requires complete extraction or installation and checks that the source has not changed. Incomplete results retain the original archive.
- Improved native table dragging, drop coverage, keyboard focus, recent-archive menus, and Browser and Glance action placement.
- Fixed a menu lifecycle loop and misleading missing-volume errors for split archives that use an unsupported compression method.

Requires macOS 26 or later.
